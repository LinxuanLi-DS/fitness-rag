# FitHer 用户调研总结（13份问卷 · 2026.05.28）

## 用户画像
- 18-24岁为主（92%），年轻女性群体
- 69%用苹果健康记录经期，23%完全不记录，仅8%用美柚

## 核心痛点（Q7 自由回答）
高频关键词：**懒、不知道练什么、不知道吃什么、难坚持**

典型回答：
- "懒"（出现4次，最高频）
- "不知道怎么控制饮食"
- "不知道每天应该练什么"
- "不能长期管理，难坚持，不同时期的状态也不同"
- "管不住嘴"

**洞察：用户最大的障碍不是功能缺失，而是缺乏主动引导和低门槛的坚持方式。AI助手+主动提醒正好解决这个问题。**

## 对现有App的不满（Q2）
- 广告太多（46%）
- 要充会员才能用核心功能（38%）
- 没有健身/饮食建议（15%）
- 功能太复杂（15%）

**机会：干净、免费、简单的产品就有差异化。**

## 想要的提醒功能（Q3）
1. 皮肤状态提醒（85%）⭐
2. 快来经期了，注意保暖（77%）
3. 今天推荐吃什么（77%）
4. 情绪调节建议（69%）
5. 今天适合做什么运动（54%）

**皮肤状态提醒是意外的高需求，可以作为特色功能。**

## 愿意记录的数据（Q4）
- 经期开始/结束（100%）— 刚需
- 症状（69%）
- 心情（69%）
- 睡眠时间（46%）
- 体重/运动/饮食/喝水（各31%）

**基础记录（经期+症状+心情）是核心，其他可以作为进阶功能逐步加入。**

## 认为的核心优势（Q6）
1. 记得我的身体数据，不用每次重复说（92%）⭐⭐⭐
2. 根据经期自动调整建议（85%）⭐⭐⭐
3. 主动提醒我，不用我去问（69%）
4. 能记录体重/运动曲线（62%）
5. 拍照就能算热量（46%）

**记忆+周期感知是最大卖点，远超其他功能。**

## 对功能组合的看法（Q5）
- 69%："还行，看具体功能"（观望态度）
- 31%："很有用，正好需要"（强需求）

**说明方向对了，但需要用实际功能说服观望者。**

---

## 产品方向验证

### 确认的差异化方向
1. **记忆持久** — 92%用户认为"记得数据不用重复说"是最大优势
2. **周期感知** — 85%希望"根据经期自动调整建议"
3. **主动引导** — 69%希望"主动提醒不用去问"，痛点是"懒"

### 下一步优先级
| 优先级 | 功能 | 依据 |
|--------|------|------|
| P0 | 经期记录（开始/结束/症状/心情） | 100%刚需，已实现 |
| P0 | AI助手感知经期数据 | 85%核心卖点 |
| P1 | 皮肤状态提醒 | 85%意外高需求 |
| P1 | 每日饮食/运动建议 | 77%需求+解决"不知道吃什么" |
| P2 | 体重曲线可视化 | 62%需求 |
| P2 | 拍照算热量 | 46%需求 |
| P3 | 喝水量记录 | 31%需求 |

### 关键洞察
> 用户的核心问题不是"没有工具"，而是"懒+不知道做什么"。
> 产品价值 = **低门槛记录 + AI主动引导 + 周期感知建议**
> 不要做功能堆砌的工具，做懂她的AI伙伴。
